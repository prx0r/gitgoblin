# License policy

This generated GitGoblin codebase is delivered **private-by-default** and does not grant a public open-source license. The operator should add the commercial/open-source license they actually want before publication.

Third-party services and datasets retain their own terms. In particular, consuming an API does not transfer the upstream server's source-code license to GitGoblin, but data licenses and API terms can still impose attribution/share-alike/use restrictions. See `docs/RESEARCH.md` and `docs/SECURITY-PRIVACY.md`.
